# استراتژی قیمت‌گذاری پویا

قیمت پایه ثابت است. پویایی فقط روی ضریب است، نه نرخ لحظه ارز.

## لنگر

| نسخه | لنگر دلار | لنگر ریال |
|------|-----------|-----------|
| پایه | ۰ | ۰ |
| خانواده | ۶ / ماه | ۲٫۹۰۰٫۰۰۰ / ماه |
| حرفه‌ای | ۱۹ / ماه | ۹٫۹۰۰٫۰۰۰ / ماه |

پایه همیشه رایگان می‌ماند تا با نشان/بلد رقابت کند.

## ضرایب

1. سالانه = ۱۰ ماه از ۱۲
2. ۱۲ فصل تقویمی جدا (نوروز تا یلدا)
3. مشتری جدید = −۱۵٪ یک‌بار
4. سقف ۱٫۲ و کف ۰٫۸
