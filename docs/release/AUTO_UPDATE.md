# به‌روزرسانی خودکار

بدون هاست اختصاصی، کانال به‌روزرسانی این است:

1. نسخه فعلی اپ
2. `GET /update/check?platform=android&current=0.1.0`
3. اگر نسخه جدیدتر بود و امضای مانیفست معتبر بود، لینک GitHub Releases برمی‌گردد
4. اگر `forceUpdate` باشد، نسخه فعلی دیگر پشتیبانی نمی‌شود

تا وقتی Release واقعی ساخته نشده، latest همان 0.1.0 است و آپدیت اجباری نیست.
