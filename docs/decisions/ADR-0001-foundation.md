# ADR-0001 — Foundation First

وضعیت: Accepted  
تاریخ: 2026-08-29

## تصمیم

پروژه از صفر با Foundation Lock شروع می‌شود. هیچ قابلیت محصولی قبل از قفل شدن قرارداد معماری، امنیت، فاز گیت، مشاهده‌پذیری و بکاپ نوشته نمی‌شود.

## دلیل

مخزن فعلی خالی است. شروع با Feature باعث بدهی امنیتی و کنترل‌نشده می‌شود.

## پیامد

- سرعت اولیه کمتر
- کیفیت و قابلیت کنترل بالاتر
- مسیر Expansion فقط بعد از هسته پایدار باز می‌شود
