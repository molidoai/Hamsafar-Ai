# Phase Gate

قانون: **NO PASS = NO NEXT PHASE**

## جریان هر فاز

Requirements → Architecture → Security/Privacy → Token/Cost → Implementation → Tests → Docs → Review → PASS/FAIL

## وضعیت‌های مجاز

- NOT STARTED
- IN PROGRESS
- BLOCKED
- FAIL
- PASS

## حداقل شواهد PASS

- خروجی فاز موجود باشد
- چک‌لیست کامل باشد
- ریسک‌های باز ثبت شده باشند
- مسیر Rollback مشخص باشد
- ادعای بدون شواهد ممنوع است
