# Backup Policy

نسخه: 0.1

## هدف

بازیابی قابل اثبات، نه فقط فایل پشتیبان.

## دامنه بکاپ

- مخزن و مستندات
- پیکربندی محیط
- دیتابیس (وقتی ایجاد شد)
- Audit و تصمیمات معماری

## حداقل عملیاتی Foundation

- Snapshot هفتگی سرور Staging
- بکاپ روزانه دیتابیس بعد از ایجاد Postgres
- نگهداری خارج از همان دیسک سرور

## قانون

بکاپ بدون تست بازیابی، تأییدشده محسوب نمی‌شود.
